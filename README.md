# Denytis — Modern Dental Practice Showcase

Modern dental care website featuring calm, patient-first preventive, cosmetic, and restorative dentistry.

## Tech Stack
- **Framework:** React 19 + Vite
- **Routing:** React Router v7
- **Animations:** Framer Motion + GSAP
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
